# backend-api-jus9-tecnologia-juridica

Este repositório consta na lista do Fundador, mas o conteúdo completo não estava disponível no ambiente desta conversa no momento do Mão na Massa final.

Incluo este diretório como marcador de continuidade para preservar a lista geral de repertórios e orientar a próxima atualização.

Quando o Fundador disponibilizar o ZIP ou a pasta deste repositório, aplicar as regras gerais:

- manter links e botões antigos;
- inserir assinatura autoral com © quando cabível;
- preservar autoria Jus 9 / Aeon Primevo;
- revisar se deve existir link para Equipe, História, Álbum, Família e Investimentos;
- não publicar segredos, tokens, chaves, `.env` ou conteúdo sigiloso.
