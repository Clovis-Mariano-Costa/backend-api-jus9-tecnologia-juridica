# Testes de integração iniciais

Esta pasta contém testes de contrato HTTP executados contra uma instância local isolada do mini backend. O token é fictício e os diretórios de auditoria/repositórios são temporários.

Execute a partir da raiz do repositório com:

```sh
npm test
```

A matriz completa e seus limites estão em [ENDPOINT-MATRIX-V01.md](../../docs/testing/ENDPOINT-MATRIX-V01.md). Os IDs API-* são provisórios e não homologam D01-D05, SEG-01 ou SEG-02.
